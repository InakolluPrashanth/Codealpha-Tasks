# 🎮 Hangman Game – CodeAlpha Internship

## 📌 Project Overview

This project is a **Hangman Game developed using Python** as part of my **CodeAlpha Internship**.

The game randomly selects a secret word from a predefined list, and the player has to guess the word one letter at a time. The player is allowed a maximum of **6 incorrect guesses** before the game ends.

## ✨ Features

- 🎲 Randomly selects a secret word.
- 🔤 Allows the player to guess one letter at a time.
- 👀 Displays correctly guessed letters.
- ❌ Tracks incorrect guesses.
- 🔢 Allows a maximum of 6 incorrect guesses.
- ✅ Displays a congratulations message when the word is guessed.
- 😔 Displays the secret word when the player loses.
- 🛡️ Validates player input.
- 🔄 Prevents repeated guesses.

## 🛠️ Technologies Used

- **Random Module**

## 🎯 How the Game Works

### Step 1 – Select Words

The program contains a predefined list of words:

```python
words = ["python", "computer", "program", "coding", "developer", "codealpha"]
```

The program randomly selects one word from the list.

### Step 2 – Start the Game

The game displays a welcome message and asks the player to guess the secret word one letter at a time.

### Step 3 – Guess Letters

The player enters a letter. The program checks whether the letter exists in the secret word.

- If the guess is correct, the letter is displayed.
- If the guess is incorrect, the incorrect guess counter increases.

### Step 4 – Track Guesses

The program stores the letters already guessed and allows a maximum of **6 incorrect guesses**.

### Step 5 – Win or Lose

If all letters in the secret word are guessed, the player wins.

If the player reaches 6 incorrect guesses, the game ends and reveals the secret word.
